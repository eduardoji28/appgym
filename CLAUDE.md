# Gemba

This project uses Gemba, an agentic development framework for Claude Code built on *genchi genbutsu*: go to the source, observe the facts, then act.

## Language

- Conversation: Spanish (Mexico). How Claude talks with the person.
- Content: Spanish (Mexico). The body of what gets written: work items, documents, notes.
- Structure: English. Section headings, labels, table headers, template fields and work item titles.

## Purpose

appgym es una app personal para registrar los días en que asistes al gym y ver tu constancia; nunca planea rutinas ni registra ejercicios, series o pesos.

Vision: https://deducoder.atlassian.net/wiki/spaces/AG/pages/86376705/Vision

## Stack

- Platform: PWA instalable en el celular
- Build: Vite con vite-plugin-pwa
- Storage: IndexedDB con idb
- Hosting: GitHub Pages
